I work in Pune, India, and I am building toward SOC analyst, cloud security and DevSecOps roles.

Most of what I do is reading configuration nobody wrote deliberately - IAM policies, security group rules, audit logs - and finding the handful of lines that actually matter. The tools I build are small, standard-library Python, and run offline against sample data that ships in the repo, because a tool you cannot run with one command is a tool nobody runs.

Lately: an IAM escalation linter, log parsers, hardening checks. Everything on my GitHub runs with python main.py against bundled sample input and prints something I would paste into a ticket.
